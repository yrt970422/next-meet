# 下一场见

## 产品需求文档（PRD）v1.0

## 1. 产品概述

### 产品名称

下一场见

### 产品定位

一个以"下一场见面"为周期的可爱成长养成游戏。

用户通过完成健身、作息等任务，在下一场见面之前慢慢调整自己的状态。

核心理念：

> 不是强迫自己完成任务，而是在期待下一场见面的过程中，好好照顾自己。

关键词： - 可爱 - 游戏化 - 陪伴 - 温柔激励 - 长期习惯

------------------------------------------------------------------------

# 2. 产品目标

## 第一阶段目标

帮助用户： 1. 建立规律运动习惯 2. 培养早睡习惯 3.
通过游戏机制增加持续动力 4. 降低健身过程中的心理压力

## 非目标

第一版不做： - 体重追踪 - 社交系统 - 排行榜 - 健身课程 - AI 健身指导 -
商业化

# 4. 周期系统

用户设置下一场日期，例如演唱会。

支持： - 自定义周期长度 - 默认推荐 21 天

周期结束： - 展示总结 - 保存历史 - 创建下一周期

------------------------------------------------------------------------

# 5. 任务系统

## 5.1 力量训练卡

默认推荐： 周期天数 × 30%

规则： 力量训练之间至少间隔一天。

完成后默认记录： - 完成力量训练

可展开记录： - 动作 - 重量 - 次数 - 备注

------------------------------------------------------------------------

## 5.2 有氧卡

默认推荐： 周期天数 × 40%

类型： - 健身操 - 拳击 - 跑走训练 - 户外活动 - 其他

------------------------------------------------------------------------

## 5.3 早睡卡

目标： 周期天数 × 90%

标准： 00:00 前睡觉

支持： - 补签 - 修改目标

补签默认限制最近 3 天。

------------------------------------------------------------------------

## 5.4 Todo List

简单任务列表。

不参与： - 成就 - 评分 - 小猪成长

------------------------------------------------------------------------

# 6. 推荐系统

首页显示"今日推荐"。

用户可以自由选择其他任务。

推荐逻辑：

## 力量训练

条件： - 目标未完成 - 距离上次力量训练 \>= 1 天

## 有氧训练

优先推荐当前完成比例最低的任务。

## 早睡

每日出现。

------------------------------------------------------------------------

# 7. 小猪伙伴系统

小猪： - 是陪伴角色 - 是成长反馈 - 是用户努力的象征

支持： - 首次命名 - 修改名字

等级：

## Lv.1

初遇的小猪

## Lv.2

运动小猪

条件： 累计完成 10 张卡

## Lv.3

元气小猪

条件： 累计完成 30 张卡

## Lv.4

闪闪发光的小猪

条件： 完成一个完整周期

## Lv.5

长期伙伴

条件： 多个周期完成

小猪不会因为失败退化。

------------------------------------------------------------------------

# 8. 成就系统

形式： 徽章墙。

状态： - 未解锁：灰色 - 已解锁：彩色

成就：

## 力量觉醒

完成周期力量目标。

## 心肺升级

完成周期有氧目标。

## 夜晚掌控者

早睡完成 \>= 90%。

## 下一场见

完成： - 力量目标 - 有氧目标 - 早睡目标

## 小猪伙伴

累计完成 50 张卡。

------------------------------------------------------------------------

# 9. 页面结构

## Home 首页

包含： - 下一场倒计时 - 小猪 - 今日推荐 - 任务进度 - Todo

## Cards 卡片页

展示任务和完成状态。

## Achievements 成就页

展示徽章。

## History 历史页

展示过去周期。

## Settings 设置页

包含： - 日期修改 - 周期修改 - 目标修改 - 小猪改名 - 数据导出

------------------------------------------------------------------------

# 10. UI 设计

风格：

-   可爱
-   手绘
-   涂鸦
-   卡牌
-   贴纸
-   温暖

参考： - 小型养成游戏 - 手账 - 卡牌收藏

避免： - 企业工具感 - 专业健身软件感

------------------------------------------------------------------------

# 11. 动画要求

必须： - 卡片完成状态变化 - 徽章解锁 - 小猪等级变化

可选： - 卡片翻转 - 折角动画

不做： - 复杂动画 - 3D效果

------------------------------------------------------------------------

# 12. 技术要求

技术栈： - React - Vite - TypeScript

数据： - localStorage

PWA： - 支持 iPhone 添加到主屏幕

不需要： - 后端 - 登录 - 数据库

------------------------------------------------------------------------

# 14. 文案要求

所有文案集中管理。

风格： - 温柔 - 可爱 - 鼓励 - 不制造负罪感

避免： - 失败 - 惩罚 - 必须完成

使用： - 今天也往前走了一点 - 小猪陪你一起努力 - 休息也是旅程的一部分

------------------------------------------------------------------------

# 15. 成功标准

第一版完成后，用户能够：

1.  在 iPhone 上打开
2.  创建周期
3.  每天完成任务
4.  看到卡片变化
5.  看到小猪成长
6.  完成周期并获得徽章
